API design

Endpoints that map to the model.

Resource-oriented routes, predictable status codes, and Pydantic schemas validating every boundary. A slice of the MedBridge surface:

POST/auth/sessionsIssue access + refresh tokens
GET/documents?cursor=&limit=Cursor-paginated, owner-scoped
POST/documentsUpload + queue extraction
GET/documents/{id}/lab-resultsNested, FK-joined read
POST/conversations/{id}/messagesAppend message, stream reply
PATCH/users/{id}Partial update, role-guarded
DELETE/auth/sessions/{id}Revoke + cascade cleanup

Conventions: versioned under /v1 · errors as RFC-7807 problem+json · idempotency keys on writes · every mutation lands in audit_log.
